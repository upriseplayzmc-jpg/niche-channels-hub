Niche Channels Hub

Niche Channels Hub is a private tool that one person uses to manage their own YouTube channels. It is not offered to the public, and nobody else can sign in to it.

With the channel owner's permission, it uses YouTube API Services to:

  • upload videos the owner has approved, and schedule them as private until their publish time;
  • set each video's thumbnail, title, description, playlist and translations;
  • read the owner's own channel statistics (views, watch time, subscribers, revenue) for a weekly report.

Everything runs on the owner's own computer. See the privacy policy.

By using this tool you agree to the YouTube Terms of Service.
